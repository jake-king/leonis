# leonis

A cross-platform Rust app framework (wgpu + SDL3) whose output is the same on every platform, with
testing, CI and release tooling built in.

Status: design. Nothing is built yet. Read [docs/SPEC.md](docs/SPEC.md) and the decisions in
[docs/decisions/](docs/decisions/).
